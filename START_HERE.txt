🔧 WITH ESP32:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Open Arduino IDE
2. Install ESP32 board (if not done)
3. Install libraries:
   • MAX30100lib (by OXullo Intersecans)
   • LiquidCrystal_I2C (by Frank de Brabander)
4. Open: d:\qqqq\ESP32_Full_Vitals.ino
5. Update configuration (lines 27-31):
   ┌──────────────────────────────────────────┐
   │ #define WIFI_SSID "YOUR_SSID"            │
   │ #define WIFI_PASS "YOUR_PASSWORD"        │
   │ #define SERVER_URL "http://YOUR_IP:4000" │
   │          (find IP with: ipconfig)        │
   └──────────────────────────────────────────┘
6. Upload to ESP32
7. Monitor Serial (115200 baud)
8. Place finger on MAX30100 sensor
9. Watch data flow to dashboard!
