Upload to ESP32:
    1. Open Arduino IDE
    2. Open ESP32_Full_Vitals.ino

    7. Set baud: 115200
    8. Reset ESP32

ESP32 → WiFi error:
    → Check SSID & password spelling
    → Ensure 2.4GHz WiFi (not 5GHz)

Frontend → No data:
    → Open browser console (F12)
    → Check for fetch errors
    → Verify backend URL in App.jsx

Backend → Build error (Render):
    → Check logs in Render dashboard
    → Ensure root directory is "backend"
    → Verify npm start works locally

CORS error:
    → Update backend/server.js cors origin
    → Include your Vercel URL
    → Commit and push
